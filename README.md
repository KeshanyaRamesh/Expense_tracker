# 💰 Expense Tracker

A simple and responsive Expense Tracker built with React and Tailwind CSS.

This application helps users manage their income and expenses, calculate their current balance, search transactions, and filter transactions by type.

## 🚀 Features

- ➕ Add income and expense transactions
- 🗑️ Delete transactions
- 🔍 Search transactions
- 🔄 Filter by All, Income, or Expense
- 💰 Automatic balance calculation
- 📈 Income and expense totals
- 💾 Local Storage support
- 📱 Responsive design
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Vite
- Local Storage
- HTML5
